# 微网与外部电网电力调控策略

本工程包含按2024年优秀论文C201主要格式组织的完整论文、三级提纲、真实计算结果、可复现程序与5个题目指定工作簿。

## 直接查看或编辑

- `main.tex`：完整论文LaTeX主文件。必须与`tables/`、`figures/`及`code/`放在同一工程中，不能只复制此文件后编译。
- `main.pdf`：已编译的论文，含单页摘要、正文、参考文献、完整代码和补充结果。
- `outline.tex`、`outline.pdf`：具体到三级标题的提纲及各部分写作要点。
- `workbooks/`：`result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx`。
- `results/summary.json`：全部18组主模型和对照实验的费用与参数。
- `results/daily_summary.csv`：四套主模型逐日费用分解及购电量。
- `results/analysis_metrics.json`：指定日期结果和月度汇总。
- `results/verification.json`：独立约束、费用和信息时序检查结果。

无需重新计算即可运行两次`xelatex main.tex`编译论文。已提供全部被引用的图表与代码。Windows环境使用宋体与黑体；其他系统可使用TeX Live的CJK字体替代，版面分页可能略有变化。图形使用Microsoft YaHei，跨系统重新绘图可在`make_evidence.py`中改为本机可用的中文字体。

## 重新计算

本次使用Python 3.12.14、NumPy 2.5.3、SciPy 1.18.1、Matplotlib 3.11.1和openpyxl。程序没有依赖pandas，也没有把Python 3.10写成已验证环境。

在工程目录运行下列命令，将`DATA`替换为原始附件目录。该目录应直接包含附件1.xlsx至附件4.xlsx以及附件5子目录，附件5内应为原始结果模板。

```text
python -m pip install -r code/requirements.txt
python code/run_experiments.py --data "DATA"
python code/export_results.py --data "DATA"
python code/check_model.py --data "DATA"
python code/make_evidence.py
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```

`run_experiments.py`默认运行全部18个方案，并在results中生成NPZ中间数组。压缩交付包未包含大型NPZ和原始赛题数据；执行上述命令即可重新生成。只运行指定方案时可以使用`--cases`，但完整图表生成需要先运行全部方案。结果含有测得运行时间，换机或重复运行时耗时会改变；正文耗时表会由`make_evidence.py`同步更新。

论文叙述中的核心数值与本次结果对应。若改变数据或模型，应同时更新正文、摘要与分析文字，不能只重生成表格就将旧结论视为已验证。

## 关键口径

1. 原始数据的0:10视为0:00—0:10时段的末端标签。模板的10分钟错位标签已在输出中统一为完整自然日，并在论文说明。原始附件未修改。
2. 1月1日初始储电量为6000 kWh。1月份连续热启动，2月至12月共334天为结果报告期，没有把2月1日重置为6000 kWh。
3. 充电和放电效率各取0.9，回路效率0.81；充放电量用母线侧口径。允许处理盈余供给，不引入售电收益。
4. 问题2使用历史预测，不使用当天未来实际量制定日前计划。风险模型采用近期误差场景中的缺额代理，实际费用通过连续反馈仿真计算；不宣称它是全年多阶段问题的全局最优解。
5. 问题3下调结算存在题意歧义。主结果采用“原计划全额支付并加收下调量50%违约费”（加罚口径）；同时重新优化并报告“退回下调部分原计划电费、再支付50%违约费”（退费口径）。每个时段相对零时原计划只结算一次生效偏差。
6. 问题3补充0+6、0+18、0+6+12、0+12+18、0+6+18等频率组合，结果见results/summary.json、tables/frequency.tex和figures/q3_frequency.pdf。滚动模型明确采用当日合同边界假设，18时预报覆盖的次日时段不直接计入当日调整费用。
7. 问题4两个指定工作簿采用未来价格未知、先预测再实际结算的主设定。价格日前已知的对照数据见summary.json及论文，不混入主结果文件；“日前已知”仅指价格曲线已知，负荷和未来光伏仍未知。
8. “计划购电量”工作表的全天购电费仅为原计划费；“调整购电量”是最终生效的常规购电绝对量，其费用列不含紧急费。实际总费用以daily_summary.csv和论文明确分解的总费用为准。
9. `spill`表示弃光或未利用的已付费供给，不能把其总量全部认定为光伏弃电。

## 格式与文献

论文采用摘要、问题重述、问题分析、模型假设、符号说明、数据处理、四问建模求解、模型评价、参考文献与附录的结构。具体字号和三线表风格参考C201，摘要单页、正文无目录、页边距2.5厘米。文献来自作者主页、HiGHS和SciPy官方文档等可核查来源，未复制往年论文的研究内容或结论。
